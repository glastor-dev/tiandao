## ⚡ Sobre el Proyecto

**Tiandao** es una solución corporativa premium desarrollada por GLASTOR® para operaciones B2B y E-Commerce. Con un enfoque absoluto en la **Developer Experience (DX)** y rendimiento excepcional (Awwwards level), integra interfaces brutalistas con cinemáticas fluidas.

El proyecto está diseñado bajo estándares estrictos de Clean Code, asegurando estabilidad a largo plazo y una escalabilidad sin precedentes impulsada por la integración de React 19 y Next.js.

## 🚀 Características Principales

- 🎨 **Diseño Premium & Brutalismo Tecnológico:** Interfaz minimalista y robusta, optimizada con animaciones avanzadas y _Smooth Scrolling_ en un entorno estético corporativo.
- ⚡ **Rendimiento Extremo:** Arquitectura Server-Side Rendering nativa para lograr una velocidad de carga sin par.
- 🛒 **Ecosistema B2B Integrado:** Flujos de presupuesto automáticos, módulos de agenda corporativa (Cal.com) e integraciones E-commerce de alto nivel.
- 🛡️ **Seguridad y Accesibilidad:** Código rigurosamente tipado en TypeScript, cumplimiento WCAG AAA en UI, y gestión segura del ecosistema web.
- ⚙️ **Stack Moderno y Ligero:** Dependencias optimizadas por **Bun**, tests robustos con **Vitest**, y linting con herramientas de nueva generación.

## 💻 Desarrollo Local

Para inicializar el entorno de desarrollo en tu máquina local, sigue estos pasos:

### Requisitos Previos

- [Bun](https://bun.sh/) instalado en tu sistema.

### Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/glastor-dev/tiandao.git
   cd tiandao
   ```

2. Configura las variables de entorno:
   Crea un archivo `.env.local` en la raíz del proyecto y añade:
   ```env
   # Requerido para consultas a la API de GitHub
   GITHUB_TOKEN=tu_token_aqui
   
   # Opcional: Lista de usuarios de GitHub separados por comas que tendrán acceso a las funciones PRO
   PRO_USERS=tu_usuario_github,otro_usuario
   ```

3. Instala las dependencias:
   ```bash
   bun install
   ```

4. Ejecuta el servidor de desarrollo:
   ```bash
   bun run dev
   ```

5. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.
